5 시험

최종 결과물의 기능과 지속 구동 가능성을 검증합니다.

시험 목표

추천부터 이동 안내까지 끊김 없는 사용자 여정

취향 입력, 도서 추천, 매장 내 위치 안내가 하나의 흐름으로 작동하는지 확인합니다. 사용자가 추천 결과를 이해하고 실제 서가까지 이동할 수 있어야 최종 결과물의 유용성이 입증됩니다.

테스트 기준: 기능 성공 여부, 오류 발생 시 복구 가능성, 반복 실행 시 안정성

기능 시험

취향 문항 입력값이 추천 결과에 반영되는지, 추천 결과가 도서 정보와 연결되는지 확인합니다.

안전·지속 시험

이동체가 지정 경로를 벗어나지 않고 반복 주행하며, 정지 조건에서 즉시 멈추는지 확인합니다.

사용성 시험

20~30대 사용자가 별도 설명 없이 흐름을 이해하고 책 발견 경험을 완료할 수 있는지 점검합니다.
